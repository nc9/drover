The substrate every other drover package depends on. Pure types and a
couple of identity builders.

## Exports

```ts
import {
  defineAgent,
  defineTool,
  // types
  type AgentSpec, type AgentInput, type AgentOutput,
  type ModelSpec, type ReasoningLevel, type SubagentConfig,
  type SystemPromptFn,
  type RunContext,

  type ToolResult, type Usage,

  type HistoryMessage,

  // errors

  SubagentLimitError, QuotaExceededError,
  CancelledError, PausedForConfirmationError,

```

## `defineAgent`

```ts
function defineAgent<I extends TSchema, O extends TSchema>(
  spec: AgentSpec<I, O>
): AgentSpec<I, O>;
```

Identity builder. Returns the spec unchanged; exists so TypeScript
infers `Static<I>` and `Static<O>` at call sites without manual
generics. See [AgentSpec](/concepts/agent-spec).

## `defineTool`

```ts
function defineTool<S extends TSchema>(tool: ToolDef<S>): ToolDef<S>;
```

Identity builder for `ToolDef`. Captures the TypeBox schema once so
`execute` sees a statically-typed `input`.

## Errors

Every drover error is a `Data.TaggedError` from Effect, so consumers
can match by `_tag`:

```ts
import { OutputValidationError } from "@drover/core";

if (err._tag === "OutputValidationError") {
  // err.attempts, err.lastIssues, err.lastText all typed
}
```

The aggregate union is `HarnessError`. Use that as the Effect error
channel when composing.

## `RunResult`

```ts
interface RunResult<TOutput = unknown> {
  runId: string;
  status: "success" | "quota" | "cancelled" | "error" | "paused";
  output?: TOutput;
  finalText: string;
  turns: number;
  durationMs: number;
  usage: { inputTokens: number; outputTokens: number; costUsd?: number; ... };
  toolCalls: readonly string[];
  error?: { tag: string; message: string };
}
```

`status: "paused"` only when storage was wired and `handle.pause()` was
called. The Promise resolution NEVER rejects — typed errors fold into
`error`.

## Tagged errors quick reference

| `_tag` | when |
| --- | --- |
| `InputValidationError` | input failed `inputSchema` |
| `OutputValidationError` | output failed `outputSchema` after retry budget |
| `SubagentLimitError` | depth/fan-out/allowed limit hit |
| `QuotaExceededError` | a run budget (turns / duration / cost) was exhausted |
| `CancelledError` | caller aborted |
| `PausedForConfirmationError` | confirm-gate triggered (reserved for runtime) |
| `ModelError` | routing miss / circuit open / provider error / auth |
| `ProviderError` | a model call failed (HTTP 4xx/5xx) or returned an empty completion; `RunResult.error` only, see below |
| `SandboxError` | sandbox refused or failed an exec/read/write |
| `StorageError` | storage adapter failure |
| `PluginError` | plugin hook threw |

## Provider failures (`ProviderError`)

pi-ai does not throw when a model call fails: it ends the stream with an
assistant message whose `stopReason` is `"error"`. drover turns that into a
failed run instead of an empty success. The run ends `status: "error"` with
`error.tag: "ProviderError"`, an `error` event is emitted before `run_end`,
and no output decode is attempted. This applies to the main loop and to the
`postSuccess` closing turn.

| final assistant message | `error.message` |
| --- | --- |
| `stopReason: "error"` with an HTTP status (402, 401, 503, ...) | `provider error 402` |
| `stopReason: "error"` with no leading status | `provider error` |
| no tool call and no non-blank text (thinking alone counts as empty) | `provider returned an empty completion (no content)` |
| none at all | `provider returned no assistant message` |

A message with only tool calls is not an empty completion. `stopReason:
"aborted"` is never a `ProviderError`: a caller abort ends `cancelled` and a
budget breach ends `quota`, as before.

By default the message carries the status and nothing else. The provider's
raw text can quote prompt content (for example words from a fetched page), so
it stays out of `RunResult.error`, the `error` event, the stored run row and
stored checkpoints (the checkpoint keeps the status-only form in
`errorMessage`). Pass `includeProviderErrorText: true` (`HarnessDeps`, or the
facade's `RunOptions` / `ResumeOptions`) to append it:
`provider error 402: 402 This request requires more credits...`.
